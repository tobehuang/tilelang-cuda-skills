# Tilelang Developing skills

This repo aims to maintain Agent skills for writting, debugging, profiling and optimizing [`tilelang`](https://github.com/tile-ai/tilelang) kernels. 

Contents are created by claude code with `skill-creator` plugin. Mainly refers to contents in `examples` and `docs` of tilelang `v0.1.9`.

The `.vscode` is intentionally kept tracked as a reference to configure highlighting for humans.
